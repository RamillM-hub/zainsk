# 3D-дашборд цеха бетонных блоков

Интерактивный 3D-дашборд: отливочный цех (столы стен, посты основания, столы крыш), основной цех (склад, покраска, лотки и заземление, отгрузка трала), кран-балка. Анимация идёт по графику дня (07:00–17:00), а **какие заказы где находятся, задаёт одна Google Таблица**, которую мастер заполняет утром.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | Главная страница. Открывать её. |
| `app.js` | 3D-сцена и анимация. |
| `data.js` | Читает таблицу и решает, где что стоит. |
| `config.js` | **Единственный файл, который надо править:** сюда вставляется ID таблицы. |
| `sheet-template.xlsx` | Шаблон таблицы с выпадающими списками. Загрузите его в Google Диск. |

## Время
По умолчанию дашборд показывает **реальное время** цеха (часовой пояс задаётся в `config.js`, `TIMEZONE`, для Казани `Europe/Moscow`). Кнопка **«Сейчас»** (оранжевая) возвращает к реальному времени. Пауза, ползунок и скорость переключают в демо-режим, чтобы можно было прокрутить любой момент суток.

## Таблица «Заказы»

Колонки: Номер заказа, Объект, Состав, Габаритный размер, Отливка стен, Отливка основания, Внутренняя покраска, Внешняя покраска, Покрытие крыши, Монтаж кабельных лотков и заземление, Отгрузка.
Статусы в колонках E–K: **Не начато / В работе / Готово / Не требуется**. Подробности на листе «Инструкция» внутри шаблона.

### Как статусы превращаются в картинку

| Статусы изделия | Где показано |
|---|---|
| «Отливка стен» или «Отливка основания» = В работе | Отливочный цех: идёт отливка. Берутся первые два изделия сверху (посты основания 1 и 2). |
| Стены и основание Готово, покраска не начата | Склад. Первые два утром едут с постов на склад, остальные стоят на складе (до 4 зданий и 4 приямков). |
| Покраска или монтаж в процессе | Основной цех, зона покраски и монтажа (до 6 зданий и 6 приямков). «В работе» показывается анимацией. |
| Всё Готово, отгрузка не Готово | Готово к отгрузке: приезжает трал, кран грузит здание и приямок. |
| «Отгрузка» = Готово | Не показывается. |

## Как запустить (пошагово)

### 1. Таблица
1. Откройте [Google Диск](https://drive.google.com), **Создать → Загрузить файл**, выберите `sheet-template.xlsx`.
2. Откройте файл, **Файл → Сохранить как Google Таблицу**.
3. Замените демо-строки своими заказами. Названия листа и колонок не менять.
4. **Настройки доступа → Все, у кого есть ссылка → Читатель**.
5. Скопируйте ID из адреса: `https://docs.google.com/spreadsheets/d/`**ЭТО_ID**`/edit`.

### 2. Подключение
В `config.js` вставьте ID: `SHEET_ID: "1AbCdEfGh...",`

### 3. GitHub
1. На github.com **New repository** (например, `ceh-dashboard`).
2. **Add file → Upload files**, перетащите все файлы (кроме `sheet-template.xlsx`) и нажмите **Commit changes**.
3. **Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save**.
4. Через 1–2 минуты откроется `https://ВАШ_ЛОГИН.github.io/ceh-dashboard/`.

Данные перечитываются при открытии страницы и каждые 5 минут (`REFRESH_MIN`).

## Что пока не из таблицы
- Арматура на стойках: демо-значения (лист «Арматура» пока не подключён).
- Время операций и длительности (07:45 перенос, 09:30 армирование, 13:00 бетон и т. д.) заданы в коде.
- Отдельная колонка «Отливка крыши»: крыша отливается вместе с основанием здания.

## Если что-то не работает
- **Демо-данные и жёлтое предупреждение**: таблица не открыта по ссылке, неверный ID или переименован лист.
- **Пустой экран**: открывайте страницу по адресу GitHub Pages (https://), а не двойным кликом по файлу.
- **Изделие не появилось**: в колонке «Состав» должно начинаться со слов «Здание» или «Приямок».
- Скрытые строки таблицы дашборд всё равно читает. Для архива ставьте «Отгрузка = Готово» или удаляйте строки.

## Безопасность
Таблица доступна всем, у кого есть ссылка, а её ID виден в `config.js` в открытом репозитории. Не кладите в неё секретные данные.
